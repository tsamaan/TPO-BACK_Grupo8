"# TPO-BACK_Grupo8 - Haversack API

API REST para e-commerce Haversack desarrollada con Spring Boot.

## 🚀 Inicio Rápido con Docker

### Opción 1: Script Automático (Recomendado)
```bash
# Doble clic en el archivo start-docker.bat
# o desde PowerShell:
.\start-docker.bat
```

### Opción 2: Docker Compose Manual
```bash
# Construir e iniciar
docker-compose up -d --build

# Ver logs
docker-compose logs -f

# Detener
docker-compose down
```

### Opción 3: Script PowerShell con opciones
```powershell
# Ver ayuda
.\docker-manager.ps1 help

# Iniciar
.\docker-manager.ps1 start

# Ver logs
.\docker-manager.ps1 logs

# Detener
.\docker-manager.ps1 stop
```

## 📋 Requisitos

- **Docker Desktop** instalado y corriendo
- **Java 21** (solo para desarrollo sin Docker)
- **Maven 3.8+** (solo para desarrollo sin Docker)

## 🔗 Enlaces

- **API:** http://localhost:8080/api
- **MySQL:** localhost:3306

## 🗄️ Base de Datos

### Credenciales (Docker)
- **Database:** `haversack_db`
- **Usuario:** `haversack`
- **Password:** `haversackpass`
- **Puerto:** `3306`
